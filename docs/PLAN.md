# ORION — план сайта

Одностраничный сайт веб-студии **ORION**. Референс структуры и подачи — [kaskadia.ru](https://kaskadia.ru),
но со своим брендом: тёмная тема, чёрный фон + оранжевый акцент. Блога и AI-анализатора нет.

Статус: план утверждён, реализация не начата.

## 1. Дизайн-система

### Токены

| Токен            | Значение                | Где                                     |
| ---------------- | ----------------------- | --------------------------------------- |
| `--bg`           | `#050505`               | фон страницы                            |
| `--surface`      | `#0D0D0F`               | карточки, поля формы                    |
| `--surface-2`    | `#141417`               | ховер карточек, вложенные блоки         |
| `--border`       | `rgba(255,255,255,.10)` | разделители секций, рамки карточек      |
| `--text`         | `#F5F5F4`               | основной текст                          |
| `--muted`        | `#A1A1AA`               | подписи, описания                       |
| `--accent`       | `#FF6A00`               | кнопки, активные ссылки, цифры, акценты |
| `--accent-hover` | `#FF8524`               | ховер                                   |
| `--accent-dim`   | `#C24A00`               | градиенты, прогресс                     |
| `--accent-glow`  | `rgba(255,106,0,.35)`   | свечение под кнопками и hero            |
| `--radius`       | `0.75rem`               | карточки; кнопки — `rounded-full`       |

Оранжевый — дорогой ресурс: акцент на CTA, активном пункте меню, номерах шагов, бейджах и
hover-состояниях. Заливать им большие площади нельзя, иначе дизайн становится дешёвым.

### Типографика

- Дисплей: **Unbounded** (700/800) — hero и заголовки секций.
- Текст: **Inter** или **Manrope** (400/500/600).
- Hero: `clamp(3rem, 12vw, 11rem)`, `line-height: .85`, `letter-spacing: -.03em`.
- Заголовки секций: `clamp(2rem, 5vw, 4rem)`.
- Eyebrow над заголовком: 12px, капс, `letter-spacing: .2em`, цвет `--muted`, точка-маркер акцентом.

### Сетка и ритм

Контейнер `max-width: 1440px`, боковые отступы 24/32px. Вертикальный ритм секций `py-24 lg:py-32`.
Между секциями — тонкая линия `--border` (местами пунктир, как на референсе).

## 3. Хедер и навигация

- `position: fixed`, высота 80px. В самом верху — прозрачный; после 40px скролла появляется
  `background: rgba(5,5,5,.72)` + `backdrop-filter: blur(12px)` + нижняя граница.
- Слева логотип `ORION` (капс, Unbounded, трекинг `-.02em`), при клике — плавно наверх.
- По центру: **Решения · Портфолио · Процесс · Тарифы**. Каждая — якорь с плавным скроллом
  (`scroll-behavior: smooth`, у секций `scroll-margin-top: 80px`).
- Активный пункт подсвечивается акцентом через `IntersectionObserver` (scroll-spy);
  на hover — подчёркивание, растущее слева направо.
- Справа: ссылка Telegram и pill-кнопка «Обсудить проект» → `#contact`.
- Мобильные (<1024px): бургер и полноэкранное меню с крупными пунктами; при открытии блокируется скролл.
- Переключателя темы нет — тема только тёмная.

## 4. Анимации

- Появление секций по скроллу: сдвиг 24px + fade, `IntersectionObserver`, один раз.
- Hero: побуквенное появление заголовка со стаггером ~40 мс и ротация слова каждые 2.5 с.
- Кнопки: заливка акцентом, растущая снизу, и сдвиг текста.
- Карточки: подъём на 4px, подсветка рамки акцентом, лёгкое свечение.
- Бегущие строки: два продублированных ряда, `transform: translateX`, пауза на hover.
- `@media (prefers-reduced-motion: reduce)` отключает всё нефункциональное.

## 5. Технические решения

Поверх текущего Vite + React 19 + TypeScript:

- **Tailwind CSS v4** (`@tailwindcss/vite`) — токены через `@theme`, быстрая вёрстка.
- **framer-motion** — появление секций, слайдер отзывов, аккордеон, мобильное меню.
- **lucide-react** — иконки.
- Шрифты через `@fontsource-variable/unbounded` и `@fontsource-variable/inter` (без внешних запросов).
- Весь текст — в `src/content/*.ts` (`solutions.ts`, `portfolio.ts`, `pricing.ts`, `faq.ts`, `reviews.ts`),
  секции только рендерят данные. Правки контента — в одном месте.
- Роутер пока не нужен: одна страница. Оставляем зависимость под будущую `/privacy`.

Структура каталогов:

```
src/
  components/
    layout/    Header, MobileMenu, Footer
    sections/  Hero, Solutions, Portfolio, CtaBand, Process, Pricing, Promises, Testimonials, Contact, Faq
    ui/        Button, Section, Eyebrow, Card, Marquee, Reveal, Accordion
  content/     тексты и данные секций
  hooks/       useScrollSpy, useScrolled, useLockBodyScroll
  styles/      index.css с @theme и базовыми слоями
```

## 7. Что нужно от заказчика

1. Список услуг и цены (или подтвердить, что берём как на референсе).
2. Кейсы для портфолио: названия, ниши, скриншоты. Если работ пока нет — делаем секцию на 3 концепта
   и помечаем как демо.
3. Контакты: телефон, почта, Telegram.
4. Логотип ORION (или собираем текстовый логотип-леттеринг).
5. Куда отправлять заявки: Telegram-бот, Formspree/Getform или почта.
6. Реквизиты для футера и текст политики конфиденциальности.
