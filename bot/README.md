# ORION bot

Telegram-бот студии на Cloudflare Workers (бесплатный тариф). Делает три вещи:

- принимает заявки с формы сайта и присылает их вам карточками с кнопками;
- присылает письма с `orion.company.web@gmail.com` (через Google Apps Script);
- даёт панель: списки заявок по статусам, статистику, заметки, настройки.

```
сайт ──POST /lead──┐
                   ├──► воркер ──► Telegram-бот ──► вы
Gmail ─POST /mail──┘        ▲
  ▲                         │ кнопки «Прочитано», «В архив»
  └──── Apps Script ◄───────┘ (необязательно)
```

## Что умеет бот

**Карточка заявки** меняется на месте при каждом действии:
🟢 Новая → 🟡 В работе → ✅ Завершена, ⛔ Отклонить и ♻️ вернуть — на любом шаге.
Под карточкой: написать клиенту (Telegram, почта или номер с WhatsApp), 📝 заметка,
🗑 удаление с подтверждением. Если заявку открыть из списка и сменить статус,
исходное уведомление в чате тоже обновится.

**Карточка письма**: открыть в Gmail, ответить, ✅ прочитано / 📬 непрочитано, 🗄 в архив,
🙈 скрыть. Длинный текст свёрнут и раскрывается по нажатию.

**Панель** (`/menu`): счётчики по статусам, списки с фильтрами и страницами,
📊 статистика (за 7 и 30 дней, конверсия, популярные типы проектов), ⚙️ настройки
(пауза почты, уведомления без звука). Панель — одно сообщение, которое
перерисовывается, а не плодит новые.

Остальным пользователям бот показывает приветствие и ссылку на сайт — заявки и
письма видит только владелец.

## Запуск

Понадобятся аккаунт Cloudflare (бесплатный) и Node.js 20+.

### 1. Бот в Telegram

1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot`, задайте имя (например, «ORION Studio»)
   и username. Сохраните токен — **никому его не пересылайте**.
2. Там же по желанию: `/setuserpic` — загрузите `public/icon-512.png`.

### 2. Воркер

```bash
cd bot
npm install
npx wrangler login
npx wrangler kv namespace create KV
```

Вставьте выданный `id` в `wrangler.toml` вместо `REPLACE_WITH_KV_NAMESPACE_ID`.
В том же файле допишите боевой домен сайта в `ALLOWED_ORIGINS` и `SITE_URL`.

Секреты (каждая команда спросит значение):

```bash
npx wrangler secret put BOT_TOKEN        # токен от BotFather
npx wrangler secret put WEBHOOK_SECRET   # любая длинная случайная строка
npx wrangler secret put MAIL_SECRET      # другая длинная случайная строка
npx wrangler deploy
```

Wrangler напечатает адрес воркера, например `https://orion-bot.имя.workers.dev`.
Откройте в браузере `https://orion-bot.имя.workers.dev/setup?key=<WEBHOOK_SECRET>` —
бот подключит вебхук, меню команд и описание.

### 3. Владелец

Напишите боту `/start` — он пришлёт ваш chat_id. Сохраните его:

```bash
npx wrangler secret put ADMIN_CHAT_ID
```

Снова `/start` — откроется панель студии.

### 4. Сайт

В корне репозитория создайте `.env.production`:

```
VITE_LEAD_ENDPOINT=https://orion-bot.имя.workers.dev/lead
VITE_SITE_URL=https://ваш-домен
```

Пересоберите и выложите сайт. Заявки с формы начнут приходить в бота.

### 5. Почта

1. Войдите в `orion.company.web@gmail.com`, откройте [script.google.com](https://script.google.com) →
   «Новый проект».
2. Замените код содержимым [`gmail/Code.gs`](gmail/Code.gs), в `WORKER_URL` впишите адрес воркера.
3. ⚙️ «Настройки проекта» → «Свойства скрипта» → добавьте `MAIL_SECRET` с тем же значением,
   что и у воркера.
4. Выберите функцию `setup` → «Выполнить» → разрешите доступ к Gmail. Появится
   минутный триггер; дальше новые письма из «Входящих» приходят в бота.
   Проверить сразу: функция `sendTest` пришлёт последнее письмо.

**Синхронизация кнопок с Gmail (необязательно).** Чтобы «Прочитано» и «В архив»
менялись и в самом ящике: «Начать развёртывание» → «Новое развёртывание» →
тип «Веб-приложение», «Запуск от имени: я», «Доступ: все». Скопируйте URL и:

```bash
npx wrangler secret put GMAIL_ACTION_URL
```

Без этого шага кнопки меняют только карточку в Telegram.

## Разработка

```bash
npm test          # тесты: воркер целиком с поддельным Telegram
npm run typecheck
npm run dev       # локальный воркер на http://localhost:8787
```

Локальные секреты для `npm run dev` кладите в `bot/.dev.vars` (в git не попадает).
